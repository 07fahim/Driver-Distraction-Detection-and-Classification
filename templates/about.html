About SafeDrive AI

SafeDrive AI is an advanced artificial intelligence system designed to detect and prevent driver distractions in real-time. Our mission is to make roads safer by identifying dangerous driving behaviors before they lead to accidents.

Our Mission

Driver distraction is one of the leading causes of road accidents worldwide. According to the National Highway Traffic Safety Administration (NHTSA), distracted driving claimed 3,142 lives in 2020 alone. SafeDrive AI aims to reduce these statistics by providing real-time detection and alerts for dangerous behaviors.

Detection Capabilities

SafeDrive AI uses state-of-the-art YOLO (You Only Look Once) ONNX deep learning models trained on thousands of images to detect 12 different types of driver distractions:

How It Works

SafeDrive AI employs a sophisticated three-stage process to ensure accurate and reliable detection:

Image Preprocessing

  • Images are resized to 640×640 pixels for optimal model performance
  • Color space conversion from BGR to RGB
  • Normalization (pixel values scaled to 0-1 range)
  • Tensor transformation (HWC to CHW format)

YOLO ONNX Inference

  • Model: Custom-trained YOLO model exported to ONNX format
  • Runtime: ONNX Runtime with CPU provider for maximum compatibility
  • Output: Detection predictions with confidence scores and class IDs
  • Confidence Threshold: 25% minimum to filter low-confidence detections
  • Local Processing: All inference runs locally for faster response times

Results Visualization

  • Text overlays displaying detected behaviors at the bottom of images/videos
  • Black background with white text for maximum readability
  • Sorted by confidence (highest confidence displayed first)
  • Frame counter for video processing
  • Confidence percentage display for each detection

Deployment Architecture

SafeDrive AI is deployed using a modern, scalable cloud infrastructure:

Production Deployment

  • Platform: Render.com (Cloud Application Platform)
  • Backend: Flask web application with Hugging Face Spaces API integration
  • Model Hosting: YOLO ONNX model hosted on Hugging Face Spaces
  • CI/CD: GitHub Actions for automated deployment pipeline
  • Containerization: Docker for consistent deployment environments
  • API Communication: Gradio Client for seamless Hugging Face Spaces connectivity

Deployment Workflow

  1. Code Push: Developer pushes code to GitHub repository (flask branch)
  2. GitHub Actions: Automated CI/CD pipeline triggers on push to flask branch
  3. Docker Build: Application containerized with Python 3.12-slim base image
  4. Dependencies: Flask, Gradio Client, Werkzeug, Gunicorn installed via pip
  5. Render Deployment: Docker image deployed via Render API with cache clearing
  6. HF Spaces API: Flask backend communicates with Hugging Face model endpoint
  7. Gunicorn Server: Production WSGI server with 2 workers and 5-minute timeout
  8. Live Application: Production-ready web app accessible globally

Docker Configuration

  • Base Image: Python 3.12-slim (Debian Trixie)
  • System Dependencies: libgl1, libglib2.0-0 for OpenCV compatibility
  • Working Directory: /app
  • Exposed Port: 5000
  • Temp Directories: /tmp/uploads and /tmp/results for file processing
  • Server: Gunicorn WSGI server for production deployment
  • Workers: 2 sync workers with 300-second timeout for video processing
  • Memory Optimization: Worker temp directory in /dev/shm (RAM)

Production Configuration

  • Max File Size: 100MB for video uploads
  • Auto Cleanup: Files older than 1 hour automatically removed
  • Lazy Client Loading: Gradio client initialized on first request
  • Error Handling: Custom error handlers for 413 and 500 status codes
  • Worker Management: Max 100 requests per worker with jitter
  • Logging: Access and error logs to stdout/stderr
  • Keepalive: 5-second connection keepalive

API Integration

  • RESTful APIs: Clean endpoints for image and video detection
  • Gradio Client: Python SDK for Hugging Face Spaces communication
  • Handle File: Efficient file transfer to remote inference endpoint
  • Base64 Encoding: Optimized image transfer for web display
  • JSON Responses: Structured data for easy frontend integration
